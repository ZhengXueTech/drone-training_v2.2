# newdrone — 教學用無人機飛行模擬器

新北市中正國中科技中心｜何政學老師

瀏覽器直接可玩的 3D 無人機飛行模擬器，供國中生課堂、社團與體驗活動使用。
不用安裝任何東西——電腦鍵盤、平板與手機觸控、實體遊戲搖桿與遙控器都支援。

## 線上遊玩

開啟 GitHub Pages 網址即可（本 repo → Settings → Pages 設定後產生）。電腦、平板、Chromebook 都能開。

## 下載後離線使用（可放隨身碟）

1. 下載整個資料夾（Code → Download ZIP，解壓縮）。
2. Windows 電腦雙擊 `啟動模擬器.bat`，瀏覽器會自動開啟 `http://localhost:8765/index.html`。
   不用安裝任何東西：電腦有 Python 就用 Python，沒有就自動改用 Windows 內建的 PowerShell。
3. 活動中不要關掉那個黑色視窗；關掉＝模擬器停止。

整包沒有任何對外連結，沒有網路也能用。成績存在那台電腦的瀏覽器裡，不會上傳到任何地方。
（不能直接雙擊 `index.html`：瀏覽器不允許以 `file://` 載入程式模組，所以需要上面的啟動檔。）

## 這一版的規則

- **只問姓名**就能開始，沒有帳號、沒有登入。
- **關卡開放順序**：先開放「基礎訓練」和「進階訓練」；第一關到第十一關全部通過後，足球對戰、情境體驗、情境對戰才會開放。
- **彩蛋**：想直接玩後面的關卡，在首頁連點最上面的標題「NEWDRONE」七下（每下間隔不要超過一秒），全部關卡會暫時開放；關掉瀏覽器就恢復。
- **飛行證書**：首頁「🏅 飛行證書」。第一到第五關全過有「基礎飛行」，第六到第十一關全過再加「進階飛行」。
  證書標示為「本機紀錄，未經認證」，簽名區是空白線，可印出後由指導老師簽名。
- 排行榜、考場代碼、雲端證書需要老師另外架設雲端，這一版沒有；那幾張卡片點進去會顯示沒有設定雲端，屬正常。

## 首頁選單

`index.html` 是分類選單首頁，5 張分類卡片各自連到一個子頁面（`pages/levels-*.html`），
點進去才會看到該分類底下的關卡卡片，並顯示各關卡完成狀態。

## 技術

Three.js r184（ES Modules，資料夾內含離線副本，教室斷網照常上課）、無後端、
成績存於瀏覽器 localStorage（`nd.progress.*`）。DPT v2 代碼為自描述格式，
之後再增加關卡也不需要修改代碼編解碼邏輯。多人對戰（PVP／PK 對戰）透過
`pages/pairing.html` 通用席位大廳配對裝置（鍵盤／觸控／搖桿／AI 皆可入座）。
