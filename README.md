# newdrone — 教學用無人機飛行模擬器

新北市中正國中科技中心｜何政學老師

瀏覽器直接可玩的 3D 無人機飛行模擬器，供國中生課堂、社團與體驗活動使用。
不用安裝任何東西——電腦鍵盤、平板與手機觸控、實體遊戲搖桿與遙控器都支援。

## 線上遊玩

開啟 GitHub Pages 網址即可（本 repo → Settings → Pages 設定後產生）。電腦、平板、Chromebook 都能開。

## 下載後離線使用（可放隨身碟）

1. 下載整個資料夾（Code → Download ZIP，解壓縮）。
2. Windows 電腦雙擊 `啟動模擬器.bat`，瀏覽器會自動開啟 `http://localhost:8765/index.html`。
   不用安裝任何東西：電腦有 Python 就用 Python，沒有就自動改用 Windows 內建的 PowerShell。
3. 活動中不要關掉那個黑色視窗；關掉＝模擬器停止。

整包沒有任何對外連結，沒有網路也能用。成績存在那台電腦的瀏覽器裡，不會上傳到任何地方。
（不能直接雙擊 `index.html`：瀏覽器不允許以 `file://` 載入程式模組，所以需要上面的啟動檔。）

## 這一版的規則

- **只問姓名**就能開始，沒有帳號、沒有登入。
- **關卡開放順序**：先開放「基礎訓練」和「進階訓練」；第一關到第十一關全部通過後，足球對戰、情境體驗、情境對戰才會開放。
- **彩蛋**：想直接玩後面的關卡，在首頁連點最上面的標題「NEWDRONE」七下（每下間隔不要超過一秒），全部關卡會暫時開放；關掉瀏覽器就恢復。
- **飛行證書**：首頁「🏅 飛行證書」。第一到第五關全過有「基礎飛行」，第六到第十一關全過再加「進階飛行」。
  證書標示為「本機紀錄，未經認證」，簽名區是空白線，可印出後由指導老師簽名。
- 排行榜、考場代碼、雲端證書需要老師另外架設雲端，這一版沒有；那幾張卡片點進去會顯示沒有設定雲端，屬正常。

## 🥽 VR 模式（實驗中，目前只有「自由飛行」）

用 Meta Quest 等頭盔的瀏覽器開上面的線上網址，進入「自由飛行」按「🥽 進入 VR」。網頁 VR 只能在 https 網址下啟動，所以下載回本機、用 http 開的版本不會出現 VR 按鈕（其他功能都正常）。
手把（美國手）：左搖桿＝油門／轉向，右搖桿＝前後／左右；右扳機按住＝自穩；A＝切飛行模式；B＝切視角（場邊／跟機）；X＝離開 VR。

## 🎲 神秘故障（挑戰條件）

第 2～11 關、情境關、自由飛行的開始畫面可以選「🎲 神秘故障：輕／重」：飛到一半會偷偷出一種狀況（搖桿偏移、單邊無力、無頭錯亂、訊號延遲、通道反向），過程中不提示，飛完先猜再揭曉真實原因與處理方式，猜對有徽章。預設關閉。

## 🏁 改裝賽道（2026-10-10 新增）
首頁「🏁 改裝賽道」：先到「🔧 機庫」換馬達、槳葉、電池、機架（沒有最強的組合），再挑 5 條賽道之一跑 3 圈計時：操場入門、森林峽谷、城市高樓（有亂流區）、室內體育館、夜間霓虹。電量不夠要降落 PIT 停機坪換電池；機庫有 9 個小任務。

## ⚽ 足球場升級、平板 QR Code（2026-10-11 新增）
- 足球三關換成「競技場」畫面（紅藍地板、LED 計分板、觀眾席、轉播式比分列），開始畫面與暫停選單的「🖥️ 畫質」可選自動／高／中／低／經典，電腦慢就選低。
- 開賽前可以選球門高度、定高開／關，還有「📐 場地」可切換 FAI（6×3×3，台灣比賽用）或 FIDA（8×4×3）。
- 在電腦上用啟動檔打開首頁，會出現「平板／手機請連這個網址」的 QR Code，平板相機掃一下就連上（要連同一個 Wi-Fi）。

## 🆚 改裝賽道：同學對戰、風、干擾區（2026-10-11 新增）
- 「🆚 同學對戰」：最多 4 人同一台電腦分割畫面一起跑（先在席位大廳指派手把／鍵盤／觸控／AI），每個人按「🔧 機體」組自己的零件，空的席位可以讓 AI 陪跑；先跑完 3 圈的贏。
- 賽道開始畫面可以選「🌬️ 風：無風／微風／強風」和「📡 干擾區」（紅色區域：畫面雜訊、操控慢半拍），有加條件的成績另外記。

## 🎮 改裝賽道 FPV 模式＋🥽 VR（2026-10-12 新增）
賽道開始畫面的「🎮 飛行方式」可選：一般（自穩，原本的飛法）、FPV 角度（第一人稱，放開回平但油門要自己抓）、FPV Acro（第一人稱，不會自己回正，真實 FPV 競速飛法）。按住空白鍵／手把 RB 可暫時自穩救機；FPV 成績另外記。
用 Meta Quest 等頭盔開 https 網址（例如 GitHub Pages 線上版）時，開始畫面會多「🥽 VR 看法」：FPV 眼鏡（眼前大螢幕播機上鏡頭，最像真實 FPV、比較不暈）或沉浸駕駛艙（人坐在機上）。按「🥽 進入 VR」後先停在起點，按 A（或右扳機）才倒數；B 換看法、Y 收起看板、X 離開。

## 🧭 統一開始畫面（2026-10-11 新增）
每一關的開始畫面都換成同一種格式：最上面一句重點和小標籤，「📖 規則說明」點開才看完整規則，「⚙ 設定」每一項一列直接點（難度、定高、風、檔位、神秘故障、場地…），最下面只有一顆「▶ 開始」。手把也能操作：上下換列、左右換選項、A 開始。手機橫拿會自動排成兩欄。另外：足球 PVP 可以關掉定高；🆚 賽道同學對戰每個人可以各自切視角（跟機／FPV／飛手）。

## 📖 操作教學
第一次按「開始」會先播一段搖桿動畫（升降、轉向、前後、左右、穿環、按鍵），每位小朋友播一次，可以按「跳過」；開始畫面的「📖 操作教學」可以再看。

## ✋ 美國手／日本手
首頁名字旁邊的「✋」、每關暫停選單、操作教學裡都能切換。美國手（預設）＝左手油門；日本手＝右手油門。手把、平板觸控、VR 手把都會跟著換；遙控器用搖桿精靈設定過的照遙控器本身。

## 首頁選單

`index.html` 是分類選單首頁，分類卡片各自連到一個子頁面（`pages/levels-*.html`），
點進去才會看到該分類底下的關卡卡片，並顯示各關卡完成狀態。

## 操作

| 裝置 | 操作 |
|---|---|
| 鍵盤 | W/S 油門、A/D 偏航、方向鍵俯仰/翻滾、Shift 半舵、C 視角、V 站位、Z 蹲、M 模式、Esc 暫停 |
| 搖桿 | 預設 Model 2（美國手）：左桿油門/偏航、右桿俯仰/翻滾；可切換日本手（首頁「✋」或暫停選單）；支援 Xbox／STARTRC／PS2 |
| 手機 | 觸控雙搖桿；直拿為「遙控器佈局」（畫面在上、搖桿在下）、橫拿為沉浸模式 |

## 技術

Three.js r184（ES Modules，資料夾內含離線副本，教室斷網照常上課）、無後端、
成績存於瀏覽器 localStorage（`nd.progress.*`）。DPT v2 代碼為自描述格式，
之後再增加關卡也不需要修改代碼編解碼邏輯。多人對戰（PVP／PK 對戰）透過
`pages/pairing.html` 通用席位大廳配對裝置（鍵盤／觸控／搖桿／AI 皆可入座）。
